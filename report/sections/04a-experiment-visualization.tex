\subsection{实验结果可视化}

为避免只依赖表格陈述实验结论，本节使用训练数据、模型评估文件和训练日志生成可复现图表。所有
图片均由 \code{scripts/generate_report_charts.py} 自动生成，数据来源与前文表格一致。训练数据
按照 60\%、15\% 和 25\% 划分训练集、验证集和独立测试集，独立测试集规模为 2280 条。

\begin{figure}[H]
  \centering
  \includegraphics[width=0.92\textwidth]{model_performance.png}
  \caption{独立测试集上不同情感分类模型性能对比}
  \label{fig:model-performance}
\end{figure}

图~\ref{fig:model-performance} 将传统基线和最终 BERT 模型置于同一坐标系中，评价指标为
\mbox{Accuracy} 和 \mbox{Macro-F1}。multilingual BERT 的 Accuracy 为 0.7461，Macro-F1 为
0.7457，分别比最佳传统模型 Logistic Regression 提高约 5.57 和 5.51 个百分点，说明上下文
表示对课程评价中的转折、否定和混合态度具有实际价值。

\begin{figure}[H]
  \centering
  \includegraphics[width=0.61\textwidth]{bert_confusion_matrix.png}
  \caption{multilingual BERT 独立测试集混淆矩阵}
  \label{fig:bert-confusion-matrix}
\end{figure}

图~\ref{fig:bert-confusion-matrix} 展示了 multilingual BERT 在 negative、neutral 和 positive
三类上的具体分类情况。正面类别识别效果最好；中性类别有 228 条被误判为负面、72 条被误判为
正面，是最主要的错误来源。这说明课程评价中的建议型表达、轻度抱怨和正负混合表达仍容易与单一
极性混淆，不能只依赖总体指标判断模型效果。

图~\ref{fig:bert-training-process}(a) 显示训练损失在两个 Epoch 内总体下降，说明模型逐渐拟合
课程评价情感分类任务。图~\ref{fig:bert-training-process}(b) 显示验证集 Accuracy 从 0.7003 提升至
0.7230，Macro-F1 从 0.7039 提升至 0.7225。第二轮训练仍带来稳定增益，但验证损失未同步明显
下降，因此当前训练轮数保持为 2，以控制过拟合风险和训练成本。

\begin{figure}[H]
  \centering
  \includegraphics[width=0.90\textwidth]{ablation_results.png}
  \caption{固定业务案例演示集消融结果}
  \label{fig:ablation-visualization}
\end{figure}

为验证各模块的实际作用，项目分别运行纯规则、TF-IDF、BERT 和完整混合流程。图
~\ref{fig:ablation-visualization} 显示，TF-IDF 单模块通过 7/12，BERT 单模块通过 10/12，
而完整流程通过 12/12。纯规则同样在这组固定案例上达到满分，是因为案例中包含较多规则能够直接
覆盖的典型表达。\textbf{固定业务案例主要用于验证课堂演示流程，不作为泛化性能结论。}为避免
规则模型满分造成误解，项目进一步使用未参与规则开发的 48 条独立压力测试检验复杂输入下的表现。

压力测试共 48 条，覆盖缩写、拼写、否定、讽刺、隐含抱怨、中英混合、长文本和混合情感，
每类 6 条。图~\ref{fig:stress-test-visualization} 表明，混合流程在独立压力测试上的 Accuracy 和
Macro-F1 均明显高于三个单独模块。其优势主要集中在缩写、拼写错误、否定、中英混合和长文本
场景：中英混合通过 6/6，缩写、拼写、否定和长文本均通过 5/6。相较 BERT 单模块，完整流程的
Accuracy 从 54.2\% 提升至 70.8\%，Macro-F1 从 54.2\% 提升至 72.2\%。另一方面，讽刺仅通过
1/6，隐含抱怨仅通过 3/6，仍是当前系统最主要的失败类型。
