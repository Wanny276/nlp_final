# 中英双语项目改造说明

本项目已从“中文课程评价分析系统”升级为“中英双语课程评价智能分析系统”。

## 项目定位

系统支持两类课程反馈：

- 中文高校课程评价，例如学生对课堂、作业、考试、实验的反馈；
- 英文在线课程评论，例如 Coursera、edX、Udemy 等平台评论。

这样既保留中文 NLP 课程项目特色，也可以合理使用 Coursera 公开数据作为扩展数据源。

## 数据格式

系统标准字段：

```csv
id,text,course,teacher,label
```

也兼容常见英文课程评论字段：

```csv
review,reviews,comment,content,rating,course_title,instructor
```

如果上传数据包含 `rating` 字段，系统会自动转换：

```text
4-5 分 -> positive
3 分 -> neutral
1-2 分 -> negative
```

## Coursera 数据接入方式

推荐做法：

1. 从 Kaggle 下载 Coursera Course Reviews 数据集；
2. 保留评论文本、课程名和评分字段；
3. 抽取一部分样本，例如 300-1000 条；
4. 上传到系统进行批量分析；
5. 报告中说明评分到情感标签的转换规则。

注意：不要把过大的原始数据文件直接提交到 GitHub。可以提交小样本数据和处理说明。

## 技术变化

- 中文文本：使用 `jieba` 分词和中文停用词；
- 英文文本：使用正则分词、小写化和英文停用词；
- 主题识别：主题标签保持中文，关键词扩展为中英双语；
- 情感分析：当前有中英双语规则兜底，后续可用 TF-IDF + Logistic Regression 训练模型替换；
- 大模型总结：Prompt 中加入语言类型和结构化分析结果。

## PPT 中可写的创新点

1. 支持中文高校评价和英文在线课程评论的双语分析；
2. 通过评分数据自动构造情感标签，降低人工标注成本；
3. 传统 NLP 结构化分析与大模型自然语言总结结合；
4. 面向课程改进场景输出主题、关键词、问题归纳和改进建议。
